Bloque A · Compilación
3 reactivos

1 de 15 · Compilación

Compilas y obtienes undefined reference to `calcular(int)'. ¿Qué ocurrió?

B. El mensaje viene de ld, después de compilar. La declaración existía (por eso el compilador aceptó la llamada), pero la definición no llegó al enlazado. Si el nombre estuviera mal escrito o faltara el #include, el error sería del compilador y diría was not declared in this scope.
2 de 15 · Compilación

¿Para qué sirve -g en g++ -std=c++17 -Wall -g main.cpp?

A. Sin -g el ejecutable no conserva la relación entre el código máquina y tus líneas de código fuente, así que el depurador no puede detenerse en ellas. Las advertencias las activa -Wall; el tamaño lo controlan -O y strip.
3 de 15 · Compilación

En VS Code pones un breakpoint y el punto rojo se ve hueco y gris. ¿Qué significa?

C. El punto hueco indica que el depurador no logró asociar esa línea con el binario. Las causas típicas son compilar sin -g o ejecutar un ejecutable viejo que no corresponde al código actual.

Bloque B · C++ básico
4 reactivos

4 de 15 · C++ básico

¿Qué imprime este programa?


int a = -1;
unsigned int b = 1;
std::cout << (a < b) << '\n';
B. Al comparar int con unsigned int, el int se convierte a unsigned: −1 se vuelve 4294967295. Compila, y con -Wall el compilador advierte comparison of integer expressions of different signedness.
5 de 15 · C++ básico

El usuario teclea 25 y luego su nombre. ¿Por qué nombre queda vacío?


int edad;
std::string nombre;
std::cin >> edad;
std::getline(std::cin, nombre);
C. El operador >> se detiene ante el espacio en blanco sin consumirlo. getline encuentra ese '\n' de inmediato y devuelve una cadena vacía. Se corrige con cin.ignore(numeric_limits<streamsize>::max(), '\n'). clear() es para el estado de error, que aquí no se activó.
6 de 15 · C++ básico

¿Cuántas veces se ejecuta el cuerpo del ciclo?


int datos[5] = {1, 2, 3, 4, 5};
for (int i = 0; i <= 5; i++)
    std::cout << datos[i];
A. Con i <= 5 el ciclo llega hasta i == 5, que ya está fuera del arreglo de índices 0 a 4. El programa suele imprimir un valor basura y seguir corriendo, que es lo que hace difícil detectar este error.
7 de 15 · C++ básico

¿Qué imprime tam si datos es un arreglo de 100 int?


void procesar(int datos[]) {
    int tam = sizeof(datos) / sizeof(datos[0]);
    std::cout << tam << '\n';
}
C. Un arreglo pierde su tamaño al pasarse a una función: el parámetro es en realidad int*. En un sistema de 64 bits, sizeof(int*) es 8 y sizeof(int) es 4, así que el cálculo da 2. El tamaño tiene que pasarse como parámetro aparte.

Bloque C · Orientación a objetos
5 reactivos

8 de 15 · POO

¿Cuál es la diferencia entre struct y class en C++?

B. En C++ un struct admite métodos, constructores, herencia y todo lo demás. La única diferencia con class es el acceso por omisión de sus miembros y de sus bases. La distinción entre ambos es una convención de estilo.
9 de 15 · POO

¿Por qué este código no compila?


class Sensor {
    const int id;
public:
    Sensor(int i) { id = i; }
};
A. Al entrar al cuerpo del constructor los miembros ya están construidos; id = i; es una asignación sobre algo constante. La forma correcta es Sensor(int i) : id(i) {}. Lo mismo aplica a los miembros que son referencias.
10 de 15 · POO

Una clase reserva memoria con new[] y la libera en su destructor. Copias un objeto con Buffer b = a; y el programa aborta al terminar. ¿Por qué?

C. El constructor de copia generado por el compilador copia el valor del puntero, no el bloque apuntado. Los dos objetos terminan apuntando a la misma memoria y cada destructor la libera: doble liberación. La solución es la regla de tres, con copia profunda.
11 de 15 · POO

Con Gerente derivada de Empleado, derivada de Persona, ¿en qué orden se destruye un Gerente?

A. La construcción va de la base a la derivada y la destrucción recorre el camino inverso. Cada clase destruye lo suyo antes de que la base destruya lo que ella administra, que es el único orden seguro.
12 de 15 · POO

¿Qué imprime este código si Circulo deriva de Figura y area() es virtual?


void mostrar(Figura f) {          // por valor
    std::cout << f.area() << '\n';
}
Circulo c(2.0);
mostrar(c);
B. Es object slicing: el parámetro por valor construye una Figura copiando solo la parte base, y con ella se pierde el enlace dinámico. El polimorfismo requiere puntero o referencia a la base: void mostrar(const Figura& f).

Bloque D · Plantillas y STL
3 reactivos

13 de 15 · STL

Defines template <typename T> class Caja en caja.h y sus métodos en caja.cpp. Al compilar aparece un error de enlazado. ¿Por qué?

B. Una plantilla genera código solo cuando se instancia con un tipo concreto. Si la definición vive en otra unidad de traducción, el compilador no puede generar Caja<int> y el enlazador no encuentra los símbolos. Por eso las plantillas van completas en el header.
14 de 15 · STL

¿Qué diferencia hay entre v[10] y v.at(10) si el vector tiene 5 elementos?

C. [] está pensado para el caso en que el índice ya se validó, y por eso no cuesta nada. at() paga una comparación y avisa del error. Acceder fuera de rango con [] suele no producir ningún síntoma visible de inmediato.
15 de 15 · STL

Necesitas guardar pares nombre → calificación y buscar por nombre con frecuencia. ¿Qué contenedor eliges?

A. map asocia clave y valor, y busca en tiempo logarítmico. El vector obliga a recorrer todos los elementos en cada búsqueda, y las listas paralelas exigen mantener a mano una correspondencia que la estructura ya podría garantizar.
