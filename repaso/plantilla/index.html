Plantilla del repositorio

Archivos para arrancar repaso-cpp · Serie de auto-estudio de C++ y POO

Estos archivos se usan en G1 · Tu código deja de perderse. Descárgalos con clic derecho y «Guardar enlace como», o ábrelos y copia el contenido.

Archivos

  1. gitignore.txt Guárdalo como .gitignore, con el punto y sin extensión, en la raíz de repaso-cpp/. Deja fuera del repositorio los objetos y ejecutables que produce el compilador.
  2. README.md Portada del repositorio: cómo compilar cualquier ejercicio y qué sesión corresponde a cada carpeta.
  3. crear-estructura.sh Crea las veinte carpetas de una vez. Opcional: puedes ir creándolas a mano conforme avanzas.

Arranque en cuatro comandos

mkdir repaso-cpp && cd repaso-cpp
bash crear-estructura.sh          # tras copiar el script aquí
git init
git add .gitignore README.md && git commit -m "Estructura inicial del repositorio"

El detalle de cada paso, y qué hacer si algo sale distinto, está en G1.
